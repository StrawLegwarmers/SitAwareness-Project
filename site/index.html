How this works. Articles come from public RSS feeds. Code groups the headlines that report the same event; an AI model checks each group and restates what each outlet reported. Every sentence cites its source, carries the date the source published it, and is checked by code (numbers, names and wording must match the cited article). Original headlines are always listed. This is a collection tool: verify at source before you rely on anything. Opinion and analysis pieces are labelled by their outlets and kept apart from reporting.
